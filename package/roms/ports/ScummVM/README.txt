ScummVM for bananaOS, with a second screen
===========================================

Start "ScummVM Two Screens" (both screens) or "ScummVM" (top screen only) from the ports list.
Put your games in roms/scummvm/<name of the game>/ and restart: they are registered automatically.

R2 goes round: mirror, verb screen (games listed in banana-split.txt), zoom.
L3 (press the left stick) changes the zoom level. A / L1 = left click, B / L2 = right click, R1 = slow pointer.
All buttons: scummvm.gptk. Everything else: https://github.com/GASQBDUV/scummvm-bananaos

log.txt in this folder is rewritten at every start; send it with a bug report.
Games are not included. ScummVM is GPL-2.0-or-later, see THIRD_PARTY.md in the repository.
